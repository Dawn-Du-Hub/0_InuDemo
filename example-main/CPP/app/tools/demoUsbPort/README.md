# 使用说明
在使用多模组时，如需要进行USB端口的FilterID 绑定，可以通过此程序获得USB端口绑定的ID.

例如： 插上模组，调用此程序后，获得模组的filter-id 为 3-13，那么在 InuServiceParams.xml 文件中修改 <FilterId>3-12</FilterId>
******************* Inuitive USB devices *******************

device 1 --- 2959:4001 (bus 3, device 17) filter-id: 3-13
