# 使用说明
此工具是检测深度数据质量好坏，给出一个等级评价。当等级低时，建议对模组进行动态标定。

判定原理：
1.拍摄一个真实平面，此平面可以是和深度相机前表面垂直面，也可以不垂直。可以是白墙，也可以是地面，平整度有要求，表面起伏最好不要超过1MM。
2.拍摄深度图，并转为点云。使用PCL 库提供的算法拟合出一个虚拟平面。
3.通过此虚拟平面，可以计算出虚拟平面相对于X，Y，Z轴的角度。
4.计算真实平面上点的数量和ROI的比例，得到填充率。
5.计算真实平面上点到虚拟平面的各个距离段点的数量和RMS。

计算结果：
|参数|说明|范围|
|-|-|-|
|FillRate|填充率|98% 以上|
|RMS|均方根|越小越好，根据不同模组和场景，此值不同|
|各距离段点云比例||根据模组使用精度要求，设置最大误差范围，如果有超出此最大值，则数据质量差|

看一个真实的例子：

RMES:2.53211%
fillRate(85031/87235):97.47%
[0~1]mm points: 7490(8.8%)
[1~2]mm points : 7306(8.6%)
[2~3]mm points : 7686(9.0%)
[3~21]mm points : 58270(68.5%)
[21~ ]mm points: 4279（5.0%）
mean distance:0.9305

说明：
1. 在ROI里应该有 87235个点，但是实际上只有 85031 个点，填充率为 97.47%，理想为 98% 较好
2. RMS 2.53211%， 这个均方根很差了，越小越好
3. 真实平面上距离虚拟平面 0~1 MM的点有 7490 个，占比 8.8%， 21 MM以上的点有 4279个占比 5%,这个太高了，造成RMS高的原因


<font color = red>
当虚拟平面和相机面垂直时，夹角可以从点云显示界面上查看，可以作为IQC工具来衡量深度相机的数据质量。
当虚拟平面不和相机面垂直时，只可以用来检测相机深度是否变差。
</font>
